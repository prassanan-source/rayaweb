# Start and stop Raya

You need Node.js 22 (that package includes npm). If you see
`npm: command not found`, Node is not installed yet.

## 1. Install Node.js / npm

Linux / macOS (no sudo — recommended):

```bash
cd rayaweb
chmod +x install-node.sh start.sh stop.sh
./install-node.sh
```

Then close the terminal, open a new one, and continue. If npm is still
missing after that:

```bash
export NVM_DIR="$HOME/.nvm"
. "$NVM_DIR/nvm.sh"
```

Ubuntu / Debian (system-wide, needs sudo):

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
node -v
npm -v
```

macOS Homebrew:

```bash
brew install node@22
```

Windows PowerShell (as Administrator):

```powershell
winget install OpenJS.NodeJS.LTS
```

Close PowerShell completely, open a new window, then `npm -v` should work.
Or install from https://nodejs.org/en/download (LTS).

## 2. Unzip and install packages

```bash
unzip rayaweb.zip
cd rayaweb
npm install
```

Windows: extract the zip in File Explorer, then in PowerShell:

```powershell
cd path\to\rayaweb
npm install
```

## 3. Start the server

```bash
npm run dev
```

or:

```bash
./start.sh
```

The site is at http://127.0.0.1:43127

## 4. Stop the server

In the same terminal: Ctrl+C

If it is still running in the background (Linux / Mac):

```bash
./stop.sh
```

or:

```bash
npm run stop
```

or:

```bash
kill $(lsof -t -i:43127)
```

Windows PowerShell:

```powershell
Get-NetTCPConnection -LocalPort 43127 -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

Copy `.env.example` to `.env.local` and add Toast keys if you want kitchen tickets. Then start again.
