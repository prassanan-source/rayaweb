# Start and stop Raya (Flask / Python)

This site is Python + Flask. You do not need Node.js or npm.

## 1. Install Python 3.12+

Linux / macOS:

```bash
./install-python.sh
```

Ubuntu / Debian:

```bash
sudo apt-get update
sudo apt-get install -y python3 python3-venv python3-pip
```

Windows: install from https://www.python.org/downloads/ and check **Add python.exe to PATH**.

## 2. Unzip

```bash
unzip rayaweb.zip
cd rayaweb
```

## 3. Start the server

Linux / macOS:

```bash
./start.sh
```

or:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m flask --app raya run --host 0.0.0.0 --port 43127
```

Windows (Command Prompt):

```bat
start.bat
```

Site: **http://127.0.0.1:43127**

## 4. Stop the server

In the same terminal: **Ctrl+C**

Or:

```bash
./stop.sh
```

Windows:

```bat
stop.bat
```

Copy `.env.example` to `.env` and add Toast keys if you want kitchen tickets. Then start again.
